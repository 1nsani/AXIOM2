# AXIOM — Idea Engine (Prototype Mode 2)

Aplikasi edukasi fisika olimpiade (OSN) berbasis web, menggabungkan:
- Komputasi simbolik (SymPy via Pyodide di browser)
- Validasi numerik (Monte Carlo)
- Inspeksi logika oleh LLM (DeepSeek API)

## Tech Stack
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Pyodide (WebAssembly) untuk SymPy
- DeepSeek API (via route serverless)
